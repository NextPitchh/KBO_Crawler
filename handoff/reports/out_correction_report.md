## 보정식

```
WE(out, s, i, half, j) = WE(1사, s, i, half, j)
                         + κ · α(i, half, j) · [ RE(out, s) − RE(1사, s) ]
```

- `WE(1사, …)` : 논문 Table 3.2 (Option A와 동일 앵커)
- `RE` : 논문 Table 2.1 MC 컬럼 (기존 `RE_TABLE` 그대로)
- `α(i, half, j)` : "득점 1점의 승리확률 가치". Table 3.2에서 같은
  (이닝·초말·주자·1사) 상태의 **인접 점수차 WE 차분을 주자상태 평균**한 값.
  이닝은 3·7회 선형 보간, 점수차 ±4 clip. 코드에서 WE 테이블로부터 자동 계산.
- `κ = 0.44` : potential-run 할인계수 (아래 Task 1-3).
- 경계 조건(9회말 끝내기 = 1.0, 연장 종료 = 1.0/0.0/0.5)은 보정 전에 먼저
  적용하고 그 경우 보정하지 않는다. `out_count == 1`이면 보정항이 정확히 0이라
  `get_we_with_boundary`와 완전히 동일하다.

### 1-2. 실증 검증

**(a) 자체 데이터 — 솔로 홈런** (주자없음·runs=1, 주자상태 불변이라 ΔWE = α):

j = ±4는 clip 때문에 실측 ≈ 0.

| j | −3 | −2 | −1 | 0 | +1 | +2 | +3 |
|---|---|---|---|---|---|---|---|
| 이론(3·7회 평균, bot) | 0.091 | 0.121 | 0.154 | 0.169 | 0.117 | 0.061 | 0.042 |
| 실측 솔로HR(bot) | 0.100 | 0.098 | 0.190 | 0.176 | 0.094 | 0.054 | 0.043 |

**(b) 독립 검증 — 네이버 원본 WPA (2024–25) 솔로 홈런** 1,392건:
이론값과 동일 수준으로 일치 (bot j=−1 이론 0.154 / 네이버 0.183,
j=0 이론 0.169 / 네이버 0.113). → 이론 α의 스케일이 옳음을 외부 지표가 확인.

### 1-3. κ (potential-run 할인계수) 확정

`α`는 **이미 스코어보드에 올라간 1점**의 가치다. `RE(out,s) − RE(1사,s)`는
**아직 실현되지 않은 기대득점** 차이이므로 승리확률 기여가 더 작다.
`α · ΔRE`를 그대로 쓰면(κ=1) 주자 있는 상태에서 아웃 효과가 과대평가된다.

**자연실험**: 순수 삼진(주자 진루 없음·득점 0)의 네이버 ΔWE를
`(주자상태 × 아웃)` 셀별로 집계 → 인접 아웃 간 WE 계단값을 실측.
15개 셀, 가중 최소제곱:

| | 잔차 RMSE |
|---|---|
| κ = 1 (task 원식 그대로) | 0.0378 |
| **κ = 0.438 (채택, 반올림 0.44)** | **0.0055** |

κ는 초/말에 안정적(0.436 / 0.445), 이닝 구간별로 0.56→0.37 완만히 감소하나
α 자체가 후반에 커지므로 `κ·α`는 더 안정적. **단일 κ = 0.44 채택.**

> 채택 근거: α는 논문 테이블에서 순수 유도(학술 근거 유지), κ만 1개
> 파라미터로 실증 보정. task_requirements.md "이론값을 기본으로 하되 실측과
> 괴리가 크면 조정" 조항에 부합. κ는 네이버 SO 데이터로 적합했으므로 그 부분
> 순환성이 있으나, 아래 부호 일치율 개선은 전 pa_result·전 주자상태에 걸쳐
> 나타나므로 보정의 실효성은 독립적으로 확인된다.
